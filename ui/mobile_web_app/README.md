# TCS Agentic OpsResolve Field — Service Representative App

A mobile-first, client-side single-page application (SPA) for field service technicians.

## Tech stack

- **React 19** + **TypeScript**
- **Vite** (build tool, outputs a fully static bundle)
- **TanStack Router** (file-based routing in `src/routes`)
- **TanStack Query** (data fetching / caching — ready for future API integration)
- **Tailwind CSS v4**

This is a pure client-side SPA. There is no server-side rendering, so the build
output is static files that can be hosted on any static host (AWS S3, CloudFront,
GitHub Pages, etc.). When dynamic data is needed later, call your APIs from the
client using `fetch` / TanStack Query — no server runtime is required here.

## Development

Requires Node.js and npm.

```sh
npm install
npm run dev      # start the dev server (http://localhost:5173)
npm run build    # produce the static bundle in dist/
npm run preview  # preview the production build locally
npm run test     # run unit tests
```

## Deploying to AWS S3

`npm run build` emits a static site into `dist/`, including a `404.html` copy of
`index.html` so client-side routes (e.g. `/jobs/123`) resolve on direct load and
refresh.

### Option A — S3 static website hosting

1. Create an S3 bucket and enable **Static website hosting**.
2. Set both the **Index document** and **Error document** to `index.html`
   (the error document fallback is what makes deep links work).
3. Upload the contents of `dist/` to the bucket root.

```sh
aws s3 sync dist/ s3://YOUR_BUCKET_NAME --delete
```

### Option B — S3 + CloudFront (recommended for production)

1. Keep the S3 bucket private and serve it through a CloudFront distribution
   (Origin Access Control).
2. Add a CloudFront custom error response: map **403** and **404** to
   **200** returning `/index.html`, so client-side routes resolve.
3. Upload with the same `aws s3 sync` command, then invalidate the cache:

```sh
aws s3 sync dist/ s3://YOUR_BUCKET_NAME --delete
aws cloudfront create-invalidation --distribution-id YOUR_DIST_ID --paths "/*"
```

## Project structure

```
index.html            # SPA entry HTML
src/
  main.tsx            # client bootstrap (mounts the router)
  router.tsx          # router + QueryClient setup
  routeTree.gen.ts    # auto-generated by @tanstack/router-plugin (do not edit)
  routes/             # file-based routes
  components/          # UI + screens
  lib/                 # utilities and mock field data
```
