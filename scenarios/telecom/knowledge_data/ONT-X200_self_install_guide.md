# ONT-X200 Self-Install Guide

> SYNTHETIC DOCUMENT created by TCS for the OpsResolve hackathon demo. Not a real OEM document.

1. Power off the old ONT. 2. Move the green fibre connector to the new ONT - do not look into the fibre. 3. Move the power and LAN cables. 4. Power on; wait for the PON light to turn solid green (up to 5 minutes). 5. Reply DONE in WhatsApp.
